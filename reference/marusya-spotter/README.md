# Споттер «Маруся» (model.bin)

Wake-word модель из прошивки VK Капсула Мини (`/usr/share/voice-agent/model.bin`).
Детектирует слово активации «Маруся» на устройстве, до стрима аудио в облако.

Проприетарная модель VK — хранится локально, в репозиторий не коммитится (см. `.gitignore`).
`sha256: 4e66655b69bd63bdf599882258aafe2dab7b691888683fd1c3996ca6abd5d372`

## Формат

- TensorFlow Lite (магия `TFL3`), schema v3, собрана TF 2.13.1.
- Архитектура: BC-ResNet (Broadcasted Residual Network), стриминговая (стейтфул).
- Вход: `serving_default_args_0:0` — `[1, 8, 40]` float32 (8 кадров × 40 лог-мел признаков).
- Выходы (две головы, по `[1, 8, 2]` float32):
  - `pos_neg_probs` — есть ключевое слово / нет;
  - `int_unint_probs` — намеренное обращение / случайное.
- 16 переменных состояния (стриминг); подграф 1 — `CALL_ONCE` инициализация состояния.

## Чтобы запустить

Модель принимает уже посчитанные лог-мел признаки, фронтенд в неё не входит.
Нужны параметры извлечения признаков из `voice-agent` (частота дискретизации,
число мел-банок = 40, размеры окна и шага, нормализация) — доснять реверсом при
сборке клиентского споттера. Для облачного эмулятора модель не требуется
(споттинг выполняется на устройстве).
