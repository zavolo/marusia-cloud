# Подключение VK Капсула Мини к эмулятору

Капсула Мини (Amlogic, Linux) ходит в то же облако `vc.go.mail.ru`, что и Капсула Нео,
и умеет тот же легаси-протокол по HTTP (`/phrase/*`, `/account/*`, `/device/*`). На «больших»
устройствах есть и gRPC-транспорт (`vk.voice.grpc.front.v1`), но он включается флагом
`is_grpc_available`; при его отсутствии клиент работает по HTTP — эмулятору достаточно HTTP.

## Что нужно на стороне сети

1. **Перенаправить DNS.** Мини резолвит имена через собственный dnsmasq с жёстко
   прописанным апстримом (публичный DNS), игнорируя DNS из DHCP. Поэтому подмены имени
   на роутере недостаточно — нужно завернуть исходящий DNS на свой резолвер:
   на шлюзе сделайте DNAT UDP/53 (от адреса колонки) на резолвер, который отдаёт
   `vc.go.mail.ru` → адрес эмулятора, а остальные запросы форвардит.

2. **TLS — без патча.** В системном хранилище Мини (`/etc/ssl/certs/ca-certificates.crt`)
   есть корень `Comodo AAA Services root`, в который выстроена цепочка сертификата эмулятора.
   Устройство доверяет серверу сразу; патч hostname, как на Нео, не нужен. Пиннинга на
   HTTP-пути нет.

3. **gRPC держать выключенным.** Эмулятор отдаёт `GET /device/toggles` →
   `{"available_toggles": {"is_grpc_available": false}}`. Даже без этого попытка gRPC к
   HTTP-эмулятору не установится, и клиент сам уходит на HTTP, но тоггл делает выбор явным.

## Что уже реализовано в эмуляторе

Весь стартовый HTTP-флоу Мини покрыт: `attach_xtoken` → `account/info`, `account/vk/info`,
`account/vk/upgrade_token` → синхронизация `device/settings/v1/*`, `content_privacy`,
`reminders` → `device/toggles` → `device/firmware`, `device/timezone/info`,
`device/speedtest/*` → `connect` (WebSocket) → фразы `phrase/create|add|result|commands` →
`stream`. Служебные `rt_logs/send`, `device/stat`, краш-синки и Mini-ручки
`device/tg_auth/mobile_send`, `device/calls/vk/hang_up` принимаются.

Набор команд колонке и коллекции настроек у Мини совпадают с реализованными.

## Отладка на устройстве

Сетевого или USB-шелла в прошивке нет (ни adbd, ни ssh/telnet). Логи и консоль — только
через UART (`ttyS0`, 115200). Для проверки подключения это не требуется: при верном DNS и
TLS колонка выходит на эмулятор сама.

## Что проверить на первом коннекте

- Формат `coordinates` в ответах `attach`/`info` — строка; если клиент Мини ждёт иную
  форму, свериться по логам UART и поправить `coordinates` в конфиге.
- Полноту `device/settings/v1/*` под конкретную сборку Мини (богаче, чем у Нео) — добить
  недостающие поля по журналу первого синка.
